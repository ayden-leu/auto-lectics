## General
### GUI
Stands for Graphical User Interface.  It refers to the visual stuff that people can interact with.





## Git-related
### Commit
Save the changes you've made to the project so far.

### Push
Upload all of your new commits to the GitHub repository.

### Pull
Download any new commits that are on the GitHub repository.

### Merge Conflict
The file modifications in one or more commits from a source aren't compatible with the file modifications in one or more commits from another source.

(e.g. a commit from Person A renames a variable to "foo", a commit from Person B renames the same variable to "bar")

### Branch
An isolated version of the project based on an existing branch at some point in time.

### Clone
Create a copy of a Git repository.
